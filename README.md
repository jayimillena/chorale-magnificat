# Ang Puso Ko'y Nagpupuri

A Filipino Marian liturgical hymn based on the **Magnificat** (Luke 1:46–55).

---

## 🎼 Song Information

- **Title:** Ang Puso Ko'y Nagpupuri
- **Composer:** Fr. Eduardo Hontiveros, SJ
- **Arranger:** Paulo Tirol
- **Performed by:** Psalmideo Chorale
